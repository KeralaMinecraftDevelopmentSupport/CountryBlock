# CountryBlock

CountryBlock is a Minecraft plugin designed to restrict or filter player access based on their geographical location (country or continent). This can be useful for servers that need to enforce region-based access rules, manage player traffic, or comply with specific regulations.

## Features
- Restrict access to your server by country.
- Configurable whitelist or blacklist for country codes.
- Lightweight and optimized for performance.
- Easy-to-use configuration file.

## Getting Started

### Prerequisites
- A Minecraft server running a compatible version of **Spigot** or **Paper**.
- Java 8 or above.

### Installation
1. Download the plugin from [Modrinth](https://modrinth.com/plugin/countryblock)
2. Place the downloaded `.jar` file into your server's `plugins` folder.
3. Restart your Minecraft server.
4. The plugin will generate a configuration file in the `plugins/CountryBlock` folder.
